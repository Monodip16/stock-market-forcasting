📐 Classical Econometric Model: ARIMA(p, d, q)

φ(B)(1 - B)d yt = c + θ(B) εt

Box-Jenkins Decomposition:

  • p (Autoregressive Order): φ(B) = 1 - ∑i=1p φi Bi (Lagged dependencies).
  • d (Differencing Degree): (1 - B)d eliminates non-stationary stochastic drift ($d=1$).
  • q (Moving Average Order): θ(B) = 1 + ∑j=1q θj Bj (Shock innovations).
  • Model Selection Criterion: Akaike Information Criterion (AIC):
    AIC = 2k - 2 ln(L̂) → Optimal Order: (0, 1, 0), AIC = 9,735.41

🧠 Deep Learning: LSTM Gating Dynamics

ft = σ(Wf [ht-1, xt] + bf)
it = σ(Wi [ht-1, xt] + bi),   C̃t = tanh(Wc [ht-1, xt] + bc)
Ct = ft ⊙ Ct-1 + it ⊙ C̃t
ot = σ(Wo [ht-1, xt] + bo),   ht = ot ⊙ tanh(Ct)

Recurrent Memory Architecture:

  • Forget Gate (ft): Discards non-essential historical memory.
  • Input Gate & Candidate (it, C̃t): Selectively stores new market movements.
  • Cell State (Ct): Constant Error Carousel (CEC) preventing vanishing gradients.
  • Output Gate (ot): Generates the hidden sequence embedding ht.
Sliding Window Sequence Modeling & Zero-Leakage Pipeline

Standard cross-validation leaks future market information into past predictions. This pipeline implements a strict zero-leakage protocol:

1. Chronological Splitting

Data is partitioned chronologically into 80% Train (2015 – July 2024, 2,392 days) and 20% Holdout Test (July 2024 – Nov 2026, 599 days). Never shuffled.

2. Isolated Normalization

MinMaxScaler is fitted strictly on the 80% training set ($X_{min}, X_{max}$). Test data is transformed using fixed training bounds without refitting.

3. Sliding Window Alignment

Each sample consists of 60 consecutive trading days ($x \in \mathbb{R}^{60 \times 1}$) predicting day 61. Test set prefixes the trailing 60 train days to cover 100% of test dates.
